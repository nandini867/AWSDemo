Project Overview  
Provision AWS infrastructure using Terraform to create a reusable, modular, and environment‑aware foundation (VPC, subnets, EC2, S3, networking).

Key Features

Modular Terraform modules for VPC, subnets, EC2, and S3.

Environment support via workspaces or variable files (dev, staging, prod).

Idempotent provisioning and safe lifecycle management.

Tech Stack  
Terraform; AWS (VPC, EC2, S3)
